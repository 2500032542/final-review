# Hospital Management System

## SDC Project Review-1

### Technology
- HTML
- CSS
- JavaScript
- Browser Local Storage

### SDC Requirements Covered

1. Problem statement: Hospital information is distributed across different activities. This prototype provides a single interface for common hospital management operations.
2. Business system and modules:
   - Admin Module
   - User/Patient Module
   - Doctor Module
   - Patient Module
   - Appointment Module
   - Pharmacy Module
   - Billing Module
3. No frameworks, backend, database or other technologies are used.
4. CSS Grid and Flexbox are used for the UI.
5. Signup and Login use Local Storage.
6. JavaScript performs role-based redirection and page navigation.
7. Major prototype functions work in the browser:
   - Login
   - Signup
   - Logout
   - Add doctors
   - View patients
   - Book appointments
   - Add medicines
   - View billing
8. The project is ready to upload to GitHub.
9. It can be demonstrated directly in VS Code using Live Server or by opening index.html.

## How to Run

1. Open the folder in VS Code.
2. Open index.html.
3. Use Live Server if installed, or open index.html in a browser.
4. Login using one of the demo accounts.
5. Demonstrate Admin and User modules.
6. Create a new account using Sign Up to demonstrate Local Storage.

## Problem Statement

Hospitals handle doctors, patients, appointments, medicines and billing. Managing these activities separately can make information difficult to organize. The Hospital Management System prototype provides a simple centralized frontend interface for these activities.

## Project Outcome

A browser-based hospital management prototype with role-based login, Local Storage authentication, module-wise navigation and working demonstration features.
